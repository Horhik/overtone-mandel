# Overtone Mandelbrot

Множество Мандельброта, управляемое обертональным пением (raylib + miniaudio).

| Голос | Что делает |
|---|---|
| Основной тон | скорость погружения: 80 Гц — медленно, 300 Гц — быстро |
| Частота выделенного обертона (500–3000 Гц) | направление движения по кругу; 500 Гц — вверх, выше — против часовой стрелки |
| Насколько обертон выделяется над соседними гармониками | скорость движения; обычная гласная не двигает |
| Тишина | картинка стоит |

Двойной тап / `R` — сброс. Удержание пальца / пробел — отдаление.
Компас в правом верхнем углу показывает, куда сейчас тянет обертон.

Настройки — `#define` в начале `main.c`: диапазоны `F0_LO/F0_HI`, `OT_LO/OT_HI`, пороги `PROM_LO/PROM_HI`, скорости.

## Android (корень репозитория)

Шаблон Raymob, raylib уже лежит внутри. GitHub Actions собирает debug-APK на каждый push (артефакт `debug-apks`). Нужны Android Studio (или SDK + NDK) и Gradle.

```
./gradlew assembleDebug
adb install app/build/outputs/apk/debug/*.apk
```

Разрешение на микрофон спрашивается при первом запуске. Рендер идёт в половинном разрешении (`RENDER_SCALE`).

## Desktop (`desktop/`)

```
cmake -S . -B build && cmake --build build -j
./build/overtone_mandel                              # микрофон
VOICE_WAV=voice_test.wav ./build/overtone_mandel     # тест на синтетическом пении
```

## Как устроено

- `voice.c` — основной тон (YIN). Яркий обертон сбивает YIN на свой период, поэтому из всех кандидатов берётся самая низкая частота, гармоническая гребёнка которой ложится на спектр. Обертон — гармоника, сильнее всех выделяющаяся над соседями (форманты гласных широкие, а обертон узкий).
- Глубокий зум: опорная орбита в double на CPU, шейдер в float считает отклонение (perturbation) с перебазированием. Предел точности — около 10¹³.
